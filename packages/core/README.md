# @vulnfuse/core

Shared, runtime-neutral TypeScript engine for the [VulnFuse](https://github.com/CAOShurong/vulnfuse) vulnerability-report correlation project.

It provides defensive parsers, a canonical evidence model, deterministic explainable matching, clustering, cross-run baseline comparison, and JSON/SARIF/CSV/Markdown exporters. The public package is not yet published to npm; use the repository workspace or the paired GitHub release packages.

See the root [README](../../README.md), [matching policy](../../docs/MATCHING.md), and [format contract](../../docs/FORMATS.md).
